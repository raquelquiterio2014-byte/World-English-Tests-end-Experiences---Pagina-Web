# World English Tests and Experiences

Página demonstrativa de aulas de inglês online, com seções Sobre, Serviços e Contato. Desenvolvida com HTML, CSS e JavaScript.

## Executar

Abra `index.html` no navegador. Os arquivos `World English 2.css`, `English World 3.js` e a imagem JPG precisam permanecer na mesma pasta. O botão do topo rola até Contato.

## Estado do formulário

O formulário é apenas uma demonstração de interface: ele não envia mensagens nem armazena dados. A mensagem exibida após o clique informa isso. Para receber contatos de verdade, será preciso conectar e testar um serviço de envio e configurar uma política de privacidade apropriada.
